# 言葉 · 日语学习工作台

独立部署的学习软件。基础教学、客观练习和本地学习记录无需模型接口；AI 功能由使用者自行配置。

## 功能

- JLPT N5–N1、商务日语和 IT 日语，按主线、章节、模块、小节学习。
- 课文讲解、词汇、客观练习、翻译、口语任务与小节统一评阅。
- 日语注音开关、点击查词、加入复习、小说阅读位置及笔记保存。
- 原创分级故事、青空文库公版作品及无 DRM EPUB / TXT 导入。
- 公版小说种子与来源声明随仓库提供；个人导入文件仍属于私有数据。
- 学习回顾中心集中展示课程、故事和限时训练错题，按来源、级别与提交范围筛选；单题重练独立记录，不覆盖原成绩。
- 生词本记录加入来源，可筛选易忘词和到期词、单独复习选定词组，并导出 Markdown。
- 跨课程、故事和小说检索与编辑学习笔记，修改同步回原小节，可导出全部或筛选结果。
- 1.7.0 补深 20 课：新增 60 个讲解小节、20 篇原创课文、60 道客观题与 40 道翻译，覆盖 N2/N1 阅读、敬语、商务和 IT 沟通。
- 完成教材小节后统一提交 AI 作业：一次请求包含本节全部译文、客观题结果、已填写的听写文字与听力理解作答，以及可选口语文字；不需要逐道翻译调用模型。
- 整节评阅保存当次提交快照，追问绑定本次任务；文字评阅不会声称已验证录音发音或真实听辨能力。
- 1.8.0 把主动回忆放在参考内容前：反馈保留原题、全部选项和本次提交，答案解析默认折叠，可在本页统一展开或收起；听力理解反馈采用相同方式。
- 新增深化短文的中文对照默认隐藏，可逐段显示或隐藏；这个开关独立于假名设置，不改变原教材内容。
- 本轮不新增课程或题目，日语题库保持 1,450 道客观题。

- 支持平板、触屏、横竖屏和分屏；支持软键盘避让、阅读设置与进度保存。
- 模型支持 Google Gemini 与 OpenAI 兼容接口，密钥由部署者自行填写。
- 学习记录还原点支持手动创建、预览、下载与恢复；导入覆盖或重置记录前先保存还原点，创建失败时保留原记录。
- 每课总结增加回忆笔记与理解程度自评，可安排 1、3、7、14 天后再看；到期课程集中出现在学习回顾中心，不发送系统通知。
- 总结页先做自检，专业与白话参考合并在默认折叠的“对照参考总结”中，按需展开核对。
- 自检回忆作为独立笔记来源接入学习回顾中心，可筛选、搜索、编辑和导出 Markdown；与原课堂笔记分别保存，编辑不覆盖自评、复习日期或测验结果。
- 自评和复习安排随学习记录保存，不改变客观题分数或自动标记课程完成，也不会自动调用模型。
- 题库扩充后保留旧提交的原题集合和判定，不把新题算作旧作业的未答扣分；原始逐题资料不足的老记录会明确提示还原范围。

## 本机启动

需要 Node.js 20 或更新版本。运行时使用 Node 内置模块及随仓库附带许可的前端依赖。

```sh
npm start
```

打开 `http://127.0.0.1:4328`。Windows 也可双击 `启动学习.bat`。
测试命令：`npm test`。测试会启动临时回环 HTTP 服务，不会调用真实模型。

## 自托管

服务默认仅监听本机。远程使用时设置 `HOST`、`PORT` 与 `PUBLIC_ORIGIN`，在前方配置 HTTPS 反向代理。
`PUBLIC_ORIGIN` 必须是完整 HTTPS 源，例如 `https://study.example.com`，不含路径。
私人部署同时设置随机 `ACCESS_TOKEN`（32–160 位字母、数字、下划线或短横线）。
首次使用 `https://study.example.com/?access=你的令牌` 打开，服务会设置 HttpOnly / Secure Cookie 并移除 URL 中的令牌。
直达链接即访问凭据，不应发布到 README、问题反馈或公开日志。配置文件由部署者在服务器上创建，仓库不提供任何可用凭据。

两种学习软件是独立仓库、独立服务，使用不同端口、域名与数据目录。
服务端学习进度和模型配置保存在 `local-config/`，浏览器保留恢复副本。
迁移私人部署应单独备份该目录；导出学习记录不包含模型密钥。
学习记录还原点属于私人运行数据，同样不得提交到公开仓库；还原点不替代模型配置、个人小说原件或录音的单独备份。
回顾和笔记检索不调用模型；只有主动提交 AI 任务时，才向自己配置的模型发送对应学习内容。

仓库附带经逐项核对许可的文化厅《敬語の指針》官方 PDF（82 页），可在资料图书馆直接阅读。
出典、原文件校验值及兼容 CC BY 4.0 的网站利用条款见 `public/data/licenses/bunka-keigo-guidelines.md`。
其余个人 PDF、商业教材、官方练习册、听力原件和所有视频均不随公开仓库发布；资料图书馆保留官方入口。
如需连接自己的媒体目录，设置 `LIBRARY_ROOT`，并在本机执行
`python scripts/build-vocabulary-resources.py --local "你的资料目录"`。
生成的私人索引和原件请保留在自己的部署中，不提交到公开仓库。

学习内容和 AI 反馈是辅助材料，不构成考试通过或职业能力的保证。
